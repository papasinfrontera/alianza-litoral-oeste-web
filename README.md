# Alianza Litoral Oeste — web pública

Landing estática de demostración para GitHub Pages.

- No incluye panel administrativo, datos privados ni servicios de backend.
- Esta versión es un respaldo de visualización y una vía independiente de prueba móvil.
- La propuesta institucional se muestra como **en evaluación**: no implica patrocinio, aval ni alianza confirmada.
